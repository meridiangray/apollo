# Set up the archive's basic wiki resources

Start with guide("start"). You do two Hydra tasks in this one session, in this order, on archive {archive}. Ask the person through ask_person for judgement calls and for every preview you would confirm.

Source: {source}

1. Shape the collections. Check out a new task from workflow collection-shape. Do: give each collection a name readers see (from its source's own title), and group the collections that should open together in a view. Done: the task is closed and the build raised no new errors.
2. Get each collection ready for its views. Check out a new task from workflow view-prep. Do: for each collection, choose its views with the person, set each view's handle, run view_check for each view switched on and fix what it reports within the rules below. Done: the task is closed and each view check's findings are in the result.

Stop when: both tasks are closed; or a step says stop; or a fix would need a new record or a merge (ask the person, then go on with the next collection).

Must not: add records, merge records or collections, delete anything, or write a fact no kept source states. Moving records between collections and creating a collection happen only when the person agreed to the plan. A question that needs the person goes through Hydra's review questions, as in every workflow.
